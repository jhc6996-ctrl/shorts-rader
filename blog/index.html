✍️ 쥬쥬체 & 홈판 형식 초안

위 카드에서 [초안 만들기]를 누르면 여기로 바로 채워져요.

발행 전 체크리스트 (쥬쥬 기준)

  1. 제목 25~30자, 앞 30자 안에 대상+숫자·반전. 핵심 유입 키워드는 절대 빼지 않기.
  2. 도입 3~5문장은 인사말 없이 결론부터. “안녕하세요”로 시작하면 홈판에서 밀려요.
  3. 1~2문장마다 빈 줄. 모바일에서 줄이 꽉 차면 이탈이 빨라져요.
  4. 인용구는 주제가 바뀔 때만 2~3개. 문단마다 넣으면 AI 티가 나요.
  5. 문체는 ~잖아요 / ~더라고요 / ~했대요 / ㅎㅎ 수다체. 어려운 말은 괄호로 풀기.
  6. AI 티 금지: 💡👉•【】, 첫째·둘째 나열, “알아보겠습니다”, 과장 수식어.
  7. 해시태그 10~15개를 본문 맨 아래에. (이 페이지 기본값은 15개)
  8. 사진 2~3장, 첫 장은 대표. 실착이 아니면 “참고용” 시점을 지키기.
  9. 개인정보 금지: 직업·근무 병원·주소·가족 실명은 본문에 넣지 않기.
  10. 발행 전 ‘AI 활용 설정’ 배지 확인. 발행 버튼은 희주 님이 직접.

홈판 공식 — 클릭은 호기심·손실회피·비교 반전에서 나옵니다. 검색어만 박은 제목(‘가습기 추천’)보다 “~했다가 0원 나온 이유”, “10만원 내고 13만원” 쪽이 잘 떠요. 앞 30자에 숫자와 대상을 넣고, 첫 3~5문장에서 결론을 먼저 주면 체류시간이 붙습니다.

피클2가 키워드를 추가하는 방법

피클2는 조사한 키워드를 아래 JSON 규격으로 만들어 이 페이지 맨 아래 입력창에 붙여넣으면 돼요. [카드로 추가]를 누르면 바로 카드가 생기고, 이 브라우저에 저장돼서 새로고침해도 남아 있어요.

필드설명
keyword카드 제목이 되는 키워드 (필수)
title홈판 훅 제목 25~30자 (필수)
cat경제·생활·쇼핑·육아·명품 중 하나
search / trend / comp검색 지표 / 상승 신호 / 경쟁도(낮음·보통·높음)
tier / reason배지 문구 / 추천 이유 한 줄
facts핵심 팩트 배열. 한 줄에 숫자 하나씩
quotes / closing / tags인용구 2개 / 마무리 질문 / 해시태그 키워드

규칙 — 출처 없는 검색량은 지어내지 말고 “미집계”로 적기. 추정이면 추정이라고 표시. 개인정보(직업·병원·주소·가족)는 JSON에도 넣지 않기. 

{
  "keywords": [
    {
      "keyword": "가습기 추천",
      "title": "가습기 3가지 방식, 12월 전에 바꿔야 하는 이유",
      "cat": "생활",
      "search": "월 4.1만",
      "trend": "+180%",
      "comp": "보통",
      "tier": "지금 뜸",
      "reason": "건조한 날씨에 검색이 몰리는데 비교 글이 적어요",
      "facts": [
        "가습기는 초음파·가열식·기화식 세 방식으로 나뉜다",
        "초음파식은 세균 번식 위험이 있어 매일 세척이 필요하다"
      ],
      "quotes": ["방식부터 정하면 가습기는 반은 고른 거예요"],
      "closing": "우리 집에는 어떤 방식이 맞을까요?",
      "tags": ["가습기", "가습기추천", "겨울가습기"]
    }
  ]
}
